# Минимальная архитектура

Infrastructure → Application → Domain. Обратные зависимости запрещены asmdef.

- Domain: обычный C#, состояние персонажей и инварианты. Без Unity и FishNet.
- Application: сценарии игры и сменяемые правила режима, без Unity.
- Infrastructure: MonoBehaviour, ScriptableObject, FishNet, Input System, AI navigation,
  представление и точка сборки зависимостей. Делить по фичам по мере реализации.
- Tests/EditMode: проверки правил; PlayMode появятся с сетевым прототипом.

Режим выбирает правила общей системы, а не копирует игрока, оружие и AI.
OutbreakRules пока задаёт только PvPvE-отношения и отсутствие заражения от контакта.
Эвакуация, невидимость и свет ещё не реализованы.

Сервер принимает команды ввода, проверяет владельца, частоту, состояние, дистанцию,
видимость и боезапас; сам определяет попадание, урон, заражение и награды.
ResolveAttack не является сетевой границей безопасности: вызывать только после этих проверок.
Клиент отвечает за ввод и представление. AI использует те же серверные сценарии.

Первый вертикальный срез: TestArena, 2 клиента FishNet, FPS-движение, одно hitscan-оружие,
один AI-зомби, здоровье и заражение. Потом раунд и смена режима.
64 игрока — будущая цель нагрузочных тестов, не текущая гарантия.
Steam, EU matchmaking, party, allocation/reconnect и постоянный профиль добавлять позже.
Backend создавать только когда появится реальный сценарий сохранения/матчмейкинга.

Не удалять существующий Netcode-шаблон до проверки замены. Новые сцены изолировать от него.
